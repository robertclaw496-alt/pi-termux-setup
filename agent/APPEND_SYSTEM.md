For tasks that genuinely require multiple iterations, recovery, or `/loop`:

- First state clear, verifiable completion criteria.
- Do not stop after a plan or an intermediate result.
- Verify results with tests, a real run, or direct inspection as appropriate.
- If any criterion remains unmet, diagnose and fix the issue, then continue only when unfinished.
- End only after confirmed completion, or when genuinely blocked by a required user permission, credential, missing data, or decision.
- Do not repeat the same unsuccessful approach without changing it based on the observed failure.
